# Programação Mobile I 📱

Este repositório é dedicado ao armazenamento de estudos, protótipos e projetos desenvolvidos na unidade curricular de **Programação Mobile I** do curso técnico em **Desenvolvimento de Sistemas (Subsequente)**, seguindo a Nova Matriz Curricular 2025.

## 📖 Sobre a Disciplina
O objetivo principal desta unidade é introduzir o aluno ao ecossistema de dispositivos móveis, focando na criação de interfaces eficientes e atraentes e na estruturação de sistemas específicos para essa plataforma.

*   **Carga Horária:** 67 horas-relógio (80 horas-aula).
*   **Semestre:** 2º Semestre.

## 🛠️ Conteúdos e Conhecimentos
De acordo com o plano de curso, este repositório abrange o estudo de:
*   **Dispositivos Móveis:** Introdução e análise de **Sistemas Operacionais** específicos.
*   **Desenvolvimento Ágil:** Uso de plataformas **"no code" e "low code"** para a criação de aplicativos móveis.
*   **UX/UI (User Experience e User Interface):** Design voltado para a experiência e interface do usuário em dispositivos móveis.
*   **Design de Serviços:** Estruturação de processos e interações no ambiente mobile.

## 🎯 Habilidades e Competências
As atividades aqui documentadas visam consolidar as seguintes habilidades:
- **Desenvolvimento de aplicações nativas** para dispositivos móveis utilizando plataformas de desenvolvimento.
- **Resolução de problemas técnicos** e estruturação de sistemas complexos para o ambiente móvel.
- **Organização de materiais e ferramentas** necessários para o fluxo de trabalho de desenvolvimento.
- **Modelagem de aplicações** e apoio técnico na documentação de sistemas móveis.
