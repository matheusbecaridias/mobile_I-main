React Native: Criando um App de Dado Virtual

Objetivo
Nesta atividade, você irá criar um aplicativo simples usando React Native que simula o lançamento de um dado virtual. O app terá uma tela com um título, uma imagem de dado que muda ao ser clicada, e um botão para reiniciar o jogo.

Descrição da tarefa
Você deve desenvolver um aplicativo com as seguintes funcionalidades:

    1. Tela principal com título:

Exiba no topo da tela o título "Próxima Rodada" centralizado.

    2. Imagem do dado no centro:

No centro da tela, mostre a imagem inicial do dado chamada dado_0 (imagem disponível na pasta assets/images).

    3. Troca da imagem ao clicar:

Quando o usuário tocar na imagem do dado, ela deve ser trocada aleatoriamente por uma das imagens:
dado_1, dado_2, dado_3, dado_4, dado_5 ou dado_6 (também disponíveis na pasta assets/images).

    4. Botão de reiniciar na parte inferior:

Na parte inferior da tela, coloque um botão com o texto "Reiniciar". Ao clicar neste botão, a imagem do dado deve voltar para a imagem inicial dado_0.

50 pontos
Você recebeu um jogo de dado virtual simples, que permite lançar o dado e mostrar o resultado na tela. Seu desafio é aprimorar o design desse jogo para torná-lo mais atraente, funcional e intuitivo para o usuário.
Analise o design atual do jogo de dado virtual, observando elementos como cores, layout, tamanho dos botões, fontes, animações e usabilidade.Proponha melhorias visuais e funcionais que possam tornar o jogo mais agradável e fácil de usar, considerando aspectos como:

    Interface gráfica (cores, formas, disposição dos elementos)
    Feedback visual ao lançar o dado (animações, efeitos)
    Clareza na exibição do resultado
    Responsividade para diferentes tamanhos de tela (especialmente em celulares)

 Desenvolver habilidades de design digital, criatividade e pensamento crítico para melhorar a experiência do usuário em um aplicativo simples.
